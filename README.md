# MediaStudyArchive

## Introduction

MediaStudyArchive is an open-source archive for organizing media communication study notes, lecture summaries, and exam preparation materials.

This project is designed to help students collect, structure, and review learning materials in a clear and accessible way.

## Features

* Organize lecture notes by subject and week
* Summarize key concepts for exam preparation
* Provide simple study templates for media and communication courses
* Make learning materials easier to review and share

## How to Use

1. Download or clone this repository.
2. Open the study note files.
3. Edit or add your own lecture notes, summaries, and exam preparation materials.
4. Use the templates to organize your learning materials.
